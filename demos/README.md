# Rao Demos

[Rao](https://www.lotas.ai/) is a fork of RStudio with a fully integrated AI assistant that can read, write, and edit code; search for context; run code and commands; and view and interpret outputs. Its source code is [available here](https://github.com/lotas-ai/rao). If you have questions or bug reports, please direct them to the [Lotas Forum](https://community.lotas.ai/).

This directory contains example use cases for Rao across different data analysis domains. Each demo showcases Rao's capabilities with real datasets and common analytical tasks.

## Available Demos

### [Gene Expression Analysis](examples/gene_expression/README.md)
Analyze gene expression data and create an R Markdown report with a PCA of samples colored by tumor stage. This demo showcases Rao's ability to handle errors and intelligently match sample IDs.

### [Survival Analysis](examples/survival_analysis/README.md)
Perform an exploratory data analysis and fit survival models. This demo showcases Rao's plotting and statistical abilities in clean data.

### [Electricity Access Analysis](examples/electricity_access/README.md)
Visualize electricity access trends in African countries over time. This demo showcases Rao's handling of real-world data formats and its ability to make interactive visuals.

### [Metagenomics Analysis](examples/metagenomics/README.md)
Analyze taxonomic abundances with metadata including PCoA visualization by diagnosis status. This demo showcases Rao's handling of large, complex datasets.

### [Italy COVID Sentiment](examples/italy_covid/README.md)
Finish the demographic analysis from a partially completed analysis on survey data from Italians early in the COVID-19 pandemic.

## Getting Started

1. Install R (version 4.0 or later) from [CRAN](https://cloud.r-project.org/)
2. Download and install [Rao](https://www.lotas.ai/download)
3. Set up your API key following the instructions in any of the individual demo READMEs
4. Choose a demo that matches your interest and follow the step-by-step instructions

Each demo is self-contained and includes:
- Data download instructions
- Sample queries
- Expected outputs and visualizations
- Tips for further exploration

Happy analyzing with Rao!
